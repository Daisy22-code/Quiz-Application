# Quiz Application

A Java-based quiz application with a graphical user interface.

## Features

- Select answers to quiz questions
- Receive a score at the end of the quiz
- See the correct answers for questions answered incorrectly
- Store quiz questions and results using text files

## Technologies

- Java
- Java GUI
- File handling

## Project Purpose

This project was developed as a university project to practice Java programming, GUI development, user interaction, and file handling.
